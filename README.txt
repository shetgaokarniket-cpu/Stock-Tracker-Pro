Stock Tracker Pro — offline Android source project.
Upload ALL contents of this extracted folder to the ROOT of your GitHub repository, including the hidden .github folder.
Open GitHub Actions > Build Android APK > Run workflow (or push to main).
After successful build, download Stock-Tracker-Pro-APK artifact and extract app-debug.apk.
This is a NEW replacement source package, not an already compiled APK.
Offline data is stored separately on each device; it does NOT sync to Firebase or between executives.
CSV reports open in Excel; PDF is available via Android Print > Save as PDF.
